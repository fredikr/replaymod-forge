# ReplayMod для Forge 1.21.11 (неофициальный порт)

[English version](README.md)

Неофициальный порт [ReplayMod](https://github.com/ReplayMod/ReplayMod) 2.6.28 (оригинал только для Fabric) на
**Minecraft Forge 1.21.11** с нашими доработками.

> Это **не** официальная сборка: авторы ReplayMod (CrushedPixel, johni0702) её не делали и не поддерживают.
> О проблемах порта пишите [сюда](https://github.com/fredikr/replaymod-forge/issues), а не в оригинальный репозиторий.

## Установка

1. Minecraft 1.21.11, Forge 61.x (проверено на 61.1.5 и 61.2.4), Java 21.
2. Положить `replaymod-1.21.11-2.6.28-forge.jar` в папку `mods` профиля Forge.
   Fabric-версию ReplayMod из этой папки убрать.
3. Мод только клиентский, на сервер ставить не нужно. Все библиотеки уже внутри jar.

Работает вместе с OptiFine (проверено с OptiFine 1.21.11 HD U J9 pre4).

## Как пользоваться

Запись включается сама при входе в мир или на сервер. В меню паузы (Esc) есть «Приостановить» и
«Закончить запись» / «Начать запись». Реплей сохраняется при выходе; открыть — кнопкой **Replay Viewer** в
главном меню. Клавиши в просмотре по умолчанию:

| Клавиша | Действие |
|---|---|
| WASD, Пробел, Shift | Полёт камеры |
| Колесо мыши | Скорость камеры |
| ЛКМ/ПКМ по существу | Смотреть его глазами (Shift — выйти) |
| P | Пауза / продолжить |
| T | Показать курсор для интерфейса реплея (затем F1 прячет интерфейс) |
| M | Маркер события |
| J / L / K | Наклон камеры влево / вправо / сброс |
| Z | Полная яркость |
| B | Список игроков |
| Q | Быстрый режим |
| I / O | Ключевой кадр позиции / времени (пути камеры) |
| H | Показать путь камеры |
| C / X | Удалить ключевые кадры / наборы ключевых кадров |
| V | Синхронизировать временную шкалу |
| Ctrl+Z, Ctrl+Y | Отменить / повторить изменение пути |

Всё переназначается в «Настройки → Управление → Replay Mod».

## Доработки порта

- **Скрытие индикатора записи** — клавиша «Показать/скрыть индикатор записи» (по умолчанию не назначена)
  прячет надпись записи в левом верхнем углу, запись при этом продолжается. Выбор сохраняется.

## Что изменено под Forge

- **Хуки экранов через события Forge.** Forge и OptiFine (он подменяет `GameRenderer` и `KeyboardHandler` и
  вызывает хуки Forge через рефлексию) не оставляют ванильных вызовов, к которым цеплялись миксины jGui, поэтому
  используются `ScreenEvent.Render.Post` и `ScreenEvent.Key*/CharacterTyped.Pre`. Индикатор записи рисуется
  слоем HUD Forge.
- **Id реестров сохраняются в реплей.** Forge может перенумеровать реестры в мире (старые одиночные миры хранят
  свои id в `level.dat`, Forge-серверы присылают свои). Пакеты записываются с этими id, а просмотр шёл с
  обычными — игрок превращался в вагонетку и реплей падал с «Ошибкой сетевого протокола». Теперь таблица
  сохраняется в реплей (`forge_registry_ids.nbt`) и включается на время просмотра (`ForgeRegistryIds`).
- **Ожидание загрузки ViaVersion.** ReplayStudio строил таблицы пакетов раньше, чем встроенный ViaVersion
  дозагружал данные, и реплей, открытый сразу после запуска игры, падал. Теперь загрузка стартует при запуске мода
  и дожидается (`ViaMappings`).
- Нет интеграции с Iris (на Forge его нет), поэтому рендер ODS (360° стерео) отключён; остальные режимы рендера
  не затронуты. Нет интеграции с ModMenu. Канал `replaymod:restrict` не регистрируется (итог как в оригинале:
  реплей с сервера, приславшего ограничения, не откроется).

## Что ещё не проверено

- Рендер в видео (нужен [FFmpeg](https://ffmpeg.org/) в `PATH` или в `.minecraft/ffmpeg/bin`).
- Редактор путей камеры, экспорт в Blender, загрузка на YouTube.
- Совместимость с другими модами рендера (Embeddium, Oculus и т.п.).
- С шейдерами OptiFine может не рисоваться рука наблюдаемого игрока (в OptiFine J9 нет нужного метода).
